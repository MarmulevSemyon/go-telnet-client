# Go Telnet Client

CLI-клиент Telnet, реализованный на Go.

Программа устанавливает TCP-соединение с удалённым сервером и предоставляет двусторонний обмен данными между локальным терминалом пользователя и удалённым узлом.

Проект демонстрирует работу с низкоуровневым сетевым взаимодействием в Go: TCP-соединения, потоками ввода/вывода, обработкой ошибок и graceful shutdown.

## Возможности

* подключение к TCP-серверу;
* интерактивный режим работы через терминал;
* передача данных из stdin;
* вывод ответа сервера в stdout;
* работа с сетевыми таймаутами;
* корректное закрытие соединения;
* обработка ошибок подключения;
* поддержка CLI-аргументов;
* автоматизация сборки через Makefile.

## Принцип работы

После запуска приложение:

1. получает адрес сервера и порт;
2. устанавливает TCP-соединение;
3. начинает читать данные из терминала;
4. отправляет их удалённому серверу;
5. выводит полученные данные пользователю.

Общий цикл:

```text
stdin
  │
  ▼
TCP connection
  │
  ▼
remote server
  │
  ▼
stdout
```

## Использование

Общий формат:

```bash
./bin/telnet-client HOST PORT
```

Например:

```bash
./bin/telnet-client localhost 8080
```

После успешного подключения пользователь может отправлять данные напрямую в TCP-соединение.

## Пример работы

Подключение к локальному серверу:

```bash
./bin/telnet-client localhost 8080
```

После ввода:

```text
hello
```

клиент отправляет:

```text
hello
```

на сервер и выводит полученный ответ.

## TCP-соединение

Для работы используется стандартный пакет Go:

```go
net
```

Подключение выполняется через:

```go
net.Dial
```

После успешного подключения создаётся объект:

```go
net.Conn
```

который используется одновременно для:

* записи данных;
* чтения ответа.

## Потоки ввода-вывода

Локальный терминал подключается к TCP-соединению:

```text
os.Stdin
    │
    ▼
net.Conn
    │
    ▼
remote server


remote server
    │
    ▼
net.Conn
    │
    ▼
os.Stdout
```

Для копирования потоков используется:

```go
io.Copy
```

что позволяет эффективно передавать данные без ручного управления буферами.

## Таймауты

При подключении используется ограничение времени ожидания соединения.

Это позволяет избежать бесконечного ожидания при недоступности сервера.

Используются:

```go
net.DialTimeout
```

и:

```go
time.Duration
```

## Обработка ошибок

Обрабатываются основные сетевые ситуации:

* неверный адрес;
* недоступный сервер;
* ошибка подключения;
* закрытие соединения;
* ошибки чтения;
* ошибки записи.

## Graceful Shutdown

При завершении работы клиента:

* закрывается TCP-соединение;
* освобождаются сетевые ресурсы;
* завершается процесс.

Используется:

```go
defer conn.Close()
```

для гарантированного освобождения ресурсов.
